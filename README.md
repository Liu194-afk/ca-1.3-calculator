# Basic Arithmetic Calculator

This is my CA 1.3 class exercise. The calculator lets the user enter two numbers and then add, subtract, multiply or divide them.

## Tools I used

- HTML for the page structure
- CSS for the colours and layout
- JavaScript for the calculations

## Steps I followed

1. I made two number input boxes and four operation buttons in HTML.
2. I added a result paragraph to show the answer or an error message.
3. I used CSS to style the inputs, buttons and result area.
4. In JavaScript, I used `document.getElementById` to get the inputs and buttons.
5. I wrote one `calculate` function and used `if...else` statements to choose the correct operation.
6. I added checks for empty inputs, invalid numbers and division by zero.
7. I added a click event listener to each button and tested all four operations.

## How to open it

Open `index.html` in a web browser. Enter two numbers and click one of the operation buttons.
